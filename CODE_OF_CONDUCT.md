# Code of Conduct

This project adopts the Contributor Covenant, version 2.1.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Enforcement

Reports of unacceptable behavior may be sent to: conduct@dentalpin.com

All reports will be reviewed and investigated promptly and fairly.
Project maintainers commit to maintaining the privacy and security of the
reporter of any incident.

## Scope

This Code of Conduct applies within all project spaces (GitHub issues, PRs,
discussions, public chat channels) and also when an individual is
representing the project in public spaces.
